# 三角洲行动 · 多杀集锦自动剪辑工具

打完一局《三角洲行动》，工具自动在录像里找出「N 秒内 M 杀」的精彩片段，剪成高光放进同一个文件夹。全部在你自己的电脑上运行，不上传任何东西。

## 能做什么

- **自动找多杀**：监控 WeGame 的录像文件夹，新录像录完后自动分析，找出 N 秒内至少 M 杀的片段（默认 90 秒内 2 杀，前留 20 秒、后留 5 秒，均可在网页里改）。
- **整理成集锦包**：每局生成一个文件夹，整局原片和高光放在一起；原片默认保留 7 天后自动删除以节省空间，高光一直保留。
- **网页里操作**：可以播放整局和高光；击杀、摸金只作为时间轴上的标记，片段单独管理：在当前位置建片段、拖动调整范围、删除，再导出想要的片段。
- **手动上传**：也可以手动选其他录像文件让工具识别。

## 环境要求

- Windows 10 / 11
- Python 3.11 及以上（项目实际使用 3.13）
- Node.js LTS（构建前端、读取官方标注点都要用）
- ffmpeg，需加入 PATH：`winget install Gyan.FFmpeg`，装完 `ffmpeg -version` 能运行即可
- 可选：NVIDIA 显卡（用 CUDA 版 PyTorch 加速识别）；没有显卡也能用 CPU，只是更慢

## 安装

```powershell

# 后端
```

## 启动

在 `backend` 目录运行：

```powershell
cd backend
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

然后用浏览器打开 http://127.0.0.1:8000/ 。构建好的网页由后端直接提供，不需要另外开前端服务。

仓库里也带了几个启动脚本（都使用脚本所在目录的相对路径）：

- `启动剪辑工具.vbs`：双击后台静默启动后端（内部调用 `start-silent.ps1`），并自动打开 http://127.0.0.1:8000/ 。日常使用推荐这个。
- `start-monitor.ps1`：只静默启动后端监控服务（端口 8000），不开浏览器。
- `start-local.bat`：以开发模式同时启动后端和 Vite 前端。
- `backend\start.bat`：以 `--reload` 方式启动后端，开发调试用。

以上脚本需要先完成上面的安装步骤。

### 更新到新版本

```powershell
git pull
cd frontend
npm install
npm run build
cd ..\backend
.venv\Scripts\pip install -r requirements.txt
```

然后重启后端（关掉旧的再双击 `启动剪辑工具.vbs`），浏览器刷新页面即可。网页文件由后端提供，只 `git pull` 不 `npm run build` 的话，页面还是旧版本。

**开机自动启动**：在网页「设置 → 基本设置」里勾选「开机自动启动」即可，立即生效。它会在 Windows「启动」文件夹放一个快捷方式，登录后在后台静默运行 `start-monitor.ps1`（不弹窗口、不开浏览器）；取消勾选就删掉这个快捷方式。

## 首次设置

1. 打开网页，进入 **设置**。
2. **游戏 ID**：填你在击杀信息里显示的名字。
3. **录像文件夹**：在 WeGame 的「精彩时刻」设置里指定录像导出文件夹，把同一个路径填到这里。
4. **集锦文件夹**：存放生成结果的位置，不能在录像文件夹里面。
5. 勾选 **自动监控**，保存。

之后每打完一局，工具会等录像文件稳定后自动分析并归档。工具第一次运行时，录像文件夹里已有的旧录像只会登记为历史文件，不会被自动处理或删除；需要时可以在网页上逐段点击处理。

## 官方标注点（可选加速）

WeGame「精彩时刻」会把击杀、摸金等事件的时间记在本机。工具只读地读取 `%APPDATA%\icreate-pc-df\wonderfulDb`，读到就不需要逐帧识别，更快更准。

- 确认是否存在：按 Win+R，输入 `%APPDATA%\icreate-pc-df\wonderfulDb` 回车。里面应有以账号数字命名、没有扩展名的文件。
- 读取需要 Node.js。
- 读不到（目录不存在、没装 Node.js 等）会自动回退到画面识别。
- 设置页会显示检测结果，也可以手动指定该目录。

## 集锦剪辑（音乐卡点）

顶部切到「集锦剪辑」，把多局的高光按一首歌剪成卡点视频：

1. **挑素材**：左边选一个文件夹（默认集锦文件夹），勾选要用的视频。集锦包里的高光 / 整局原片会自动读取击杀时间；其他视频点开后停在开枪那一帧按 M（或「在这一帧标击杀」）手动标。
2. **选歌**：右边「剪辑设置 → 歌曲」选 mp3 / flac / wav，工具会分析节拍和听感最重的重音。
3. **选风格**：风格预设一键设好开头 / 转场 / 结尾，也可以单独改：开头（模糊渐显、推近、白闪、标题文字、自定义片头视频）、转场（硬切、推镜、重击、闪白、闪黑、甩镜）、结尾（渐黑、模糊渐黑、自定义片尾视频）。
4. **自动编排**：击杀落在重音和拍点上，每个击杀前留前因，长时间没击杀自动快进。
5. **手动微调**：时间线上拖击杀菱形换拍点、拖镜头尾巴改长度（自动吸附到拍点，按住 Alt 不吸附）；选中镜头可换转场、换素材、调顺序、删除。空格预览，← → 按拍移动。
6. **出片**：成片保存到集锦文件夹下的 `音乐卡点集锦/`。

**剪辑助手**：「助手」页填入 Claude API Key 后，可以直接说「剪一版 45 秒的，最多杀的那段放在 drop 上」「转场换成甩镜」，助手会改参数、编排和微调时间线，改完仍可手动调整。只发送文件名、击杀时间、节拍和参数，不上传视频和音频。

依赖：`librosa`（节拍分析）和 `anthropic`（助手）已加入 `backend/requirements.txt`，更新后在 backend 目录重新运行 `.venv\Scripts\pip install -r requirements.txt`。命令行用法见 [montage/README.md](montage/README.md)。

## 播放器快捷键

在「自动剪素材」里看录像时（光标不在输入框里即可）：← → 微移播放头（步长随时间轴缩放，Shift 10 倍），`,` `.` 逐帧，空格 / K 播放暂停；先点一下时间轴后 N 建片段，I / O 设入点 / 出点，Delete 删除选中片段。

## 什么时候处理新录像

设置 → 「什么时候处理新录像」有三种：

- **打完游戏再处理（默认）**：检测到正在玩游戏就暂停，游戏关掉后再等几分钟（可设置）才开始。识别途中开始玩，会中断这次识别，把这局放回队列，玩完后重新开始，不跟游戏抢显卡。
  - 已内置三角洲行动和常见游戏的进程名，也可以在设置里补充别的游戏进程名。
  - 可选「任何全屏程序都算在玩」，不在名单里的全屏游戏也能识别；浏览器、播放器全屏看视频不算。
- **录完马上处理**：不管在不在玩，新录像写完就开始。
- **只在我点开始时处理**：新录像只登记到列表，在网页里点「开始处理」或「全部开始处理」。

检测只用 Windows 自带的进程列表和窗口信息，不需要额外安装任何东西。

## 使用显卡加速

设置 → 识别 → **使用显卡加速**。需要已安装 CUDA 版 PyTorch；没有 NVIDIA 显卡请关闭此项，使用 CPU 识别。

## 集锦文件夹里有什么

每局一个文件夹，里面包括：

- `整局原录像.mp4`：整局原片（到期自动删除，见下）
- 高光视频：识别出的多杀片段
- `录像说明.txt`：这一局的简要说明
- `识别记录.json`：识别过程和结果的详细记录
- `剪辑工程.json`：你在网页里改过的标记和片段
- `手动剪辑/`：你手动导出的成片

## 原片保留与删除

- 默认：归档成功后保留原片 7 天，到期自动删除，高光和记录都保留。
- 想一直保留：在网页里点「保留这局原片」。
- 想手动清理：可以只删原片，或删除整个集锦包。
- 导出失败、成片损坏等情况会暂停自动清理并在网页显示原因。

## 常见问题

**集锦里的击杀数和游戏结算不一样？**
集锦按「不同干员」计数：同一个人被击倒再补杀只算一次；摸金、载具击毁不计入。结算数则按游戏自己的口径，所以可能不同。

**网页里视频黑屏？**
先按 Ctrl+F5 强制刷新页面。

**打不开网页 / 启动时报端口 8000 被占用？**
多半是后端已经在后台运行了（比如开了开机自动启动），直接打开 http://127.0.0.1:8000/ 即可。确实要重启时，在任务管理器里结束 `python.exe`（命令行里带 `uvicorn`）再启动。

**提示「只允许从本机访问」？**
后端能删除文件、修改设置，所以只接受 `127.0.0.1` / `localhost` 访问，也会拒绝其他网站发来的修改请求。请用 http://127.0.0.1:8000/ 打开，不要用局域网 IP 或自定义域名。

**我玩 4:3 拉伸，画面比例不对？**
在导出/预览选项里打开「拉伸为 16:9」。

## 隐私说明

所有分析、剪辑和存储都在你自己的电脑上进行，不上传任何视频或数据。服务只监听 127.0.0.1，局域网和外网都访问不到；浏览器里其他网站也不能借你的浏览器调用它的接口。

## 开发

前端开发模式（改 Vue 代码后热更新）：先按上面启动后端，再另开一个终端：

```powershell
cd frontend
npm run dev
```

打开 http://127.0.0.1:5173/ ，`/api` 请求会被 Vite 转发到 8000 端口的后端。`start-local.bat` 做的就是这两步。

运行测试：

```powershell
cd backend
.venv\Scripts\python.exe -m unittest discover -p "test_*.py"
```

其中 `test_real_feed.py` 依赖本地的真实截图 `backend/tests/fixtures/killfeed/`（不随仓库发布），目录不存在时会自动跳过。

技术栈：后端 FastAPI；前端 Vue 3 + Vite + Pinia + video.js；视频与识别用 ffmpeg、OpenCV、EasyOCR。

```
backend/
  app/            后端代码（main.py 入口，api/ 路由，services/ 识别、归档、导出等逻辑）
  assets/         识别用资源
  test_*.py       单元测试
  requirements.txt
  start.bat
frontend/
  src/            Vue 3 前端源码
  package.json
start-local.bat / start-silent.ps1 / start-monitor.ps1 / 启动剪辑工具.vbs   启动脚本
```

识别依赖当前版本游戏的击杀信息界面；修改 HUD 缩放或录像比例后，识别效果可能下降。
